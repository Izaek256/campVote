Buttons & actions

.btn

Primary is solid green. Secondary is a black outline that inverts on hover. Danger is red and always asks for confirmation. Click the demo buttons: each runs the loading and confirmation sequence.

Variants

.btn .primary .danger .danger-o .ghost
One primary per view. Labels are verbs: Submit ballot, Approve candidate.

Sizes

.sm 34 · base 44 · .lg 56
Voters use .lg on ballot screens. Mobile targets never go below 44px.

States

hover · focus · disabled
Focus is a 3px green ring offset 2px. Disabled buttons explain why in nearby text, never only by greying out.

Click: spinner then confirmation

data-state idle / loading / done
Width does not change during the sequence. Spinner for unknown time, then a drawn tick for 1.4 s, then back to idle.

Rules

do and do not
  • Use only tokens. No hex values in components.
  • Corners come from var(--r). Never hard-code a radius.
  • Borders: 1px --line for hairlines, 1.5px --line-strong for controls and key panels.
  • Symmetric padding. Equal left and right, equal columns, centered icons.
  • Status = text label + shape or hatch. Provisional or under review uses the hatch.
  • Real buttons, labels, focus ring, 44px mobile targets, WCAG 2.2 AA.
  • Times in EAT. Percentages name their denominator. Digits tabular.
  • No shadows on cards, no gradients, no emoji, no amber or blue, no rounded pills.
  • Never show a voter next to a choice. Leaders are "Leading", not "Winner", until certified.
  • No confetti or bouncing. Motion confirms work only.
